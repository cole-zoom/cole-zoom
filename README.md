# hey, i'm cole 👋

based in Waterloo. i make videos and build things with LLMs, search, and data, plus a lot of things involving Clash Royale.

## video

i make explainers, promos, and episodes, and most of the animation is built in code.

- **3D motion graphics in Remotion**: whole explainers as one continuous 3D world, with every beat keyed to the voiceover
- **real data on screen**: the numbers, rows, and query results in a video come from real queries, not typed by hand
- **Blender** for 3D scenes and assets, **DaVinci Resolve / Fusion** for comps and promos
- **voiceover**: scripting, recording, de-echo and mastering

## what i'm working on

- **[skylanders](https://github.com/cole-zoom/skylanders)**: *Skylanders: Spyro's Adventure* (Wii) running fully client-side in the browser on WebAssembly, with all 530 figures through an emulated Portal of Power. C++
- **[bot-77](https://github.com/cole-zoom/bot-77)**: a Clash Royale AI built from gameplay footage. It turns recorded games into a play-by-play event log in LanceDB, learns what strong players play next, then plays in BlueStacks and learns from its own games. Python
- **[Furnace](https://github.com/cole-zoom/Furnace)**: a personal CRM for one person, with tasks, Google Calendar meetings, and Gemini-summarised transcripts, built to feel like Attio. TypeScript
